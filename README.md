# Sistema-de-gestion-de-emergencias
PACI 2 Programación Orientada a Objetos
-----------------------------------------------------------------------

# Situación
Una central de atención de emergencias necesita registrar incidentes y asignar recursos disponibles. Los recursos pueden incluir vehículos, personal y equipos.

El sistema deberá permitir
* Registrar emergencias.
* Clasificar emergencias.
* Consultar recursos disponibles.
* Asignar recursos.
* Actualizar estados.
* Registrar atención.
* Consultar las emergencias atendidas.

Administrador
* Registrar tipos de emergencia.
* Configurar prioridades.
* Registrar recursos.
* Configurar parámetros de asignación.

Operador
* Registrar emergencias.
* Consultar recursos.
* Asignar recursos.
* Actualizar estados.
* Finalizar atención.
